# 组件测试

本文档展示所有类 Widget 组件及其变体，按从最小可组合单元到较大组合的顺序组织。

## 术语

- **Media（媒体）**：附加到 commit 的外部内容。四种 kind：link、social-embed、video、image
- **Commit（提交）**：工作项（项目、演讲、文章、职位、社交），可附加媒体
- **SocialEmbed（原生嵌入）**：原生社交平台 widget（X / Instagram / TikTok），与 card 区分

---

## 1. 媒体

媒体组件是嵌入外部内容的原子构建块。`Media` 组件可自动检测 URL 并按对应 kind 渲染。

### 组件层级

```
                    Media（统一入口）
                           │
       ┌──────────┬────────┴────────┬──────────┐
       │          │                 │          │
     Video    SocialEmbed   Link / LinkCard  Figure
       │          │
  ┌────┼────┐  ┌──┴───┐
  │    │    │  │  │   │
 YT  Bili Vimeo X IG TikTok
```

- **Media**：统一入口，自动检测 URL 并路由到对应组件
- **Video**：视频平台，带点击播放的封面
- **SocialEmbed**：使用官方 SDK 的原生社交平台 widget
- **Link / LinkCard**：同一个 URL 的两种呈现 —— pill（角标）vs card（OG 卡片）

### Media（强制 Kind）

使用 `as` prop 可以强制指定渲染 kind，跳过自动检测。当你想以不同于检测 kind 的方式渲染 URL 时很有用。

#### 强制 YouTube 显示为 Link Pill

<Playground>
```tsx

```

</Playground>

<Playground>

### Commit 变体

| 变体 | 描述 | 使用场景 |
|------|------|----------|
| `timeline` | 显示图标，时间线优化间距 | /works 页面 |
| `card` | 独立带边框/背景框架 | MDX（默认）|
| `bare` | 最简无框 | Widget 内部 |

## 快速参考

### 媒体 Kind

| Kind | 属性 | 描述 |
|------|------|------|
| `link` | `url`, `present`（`card`）, `preview?` | URL 呈现为 OG 卡片（行内 pill 仅用于 MDX 正文）|
| `social-embed` | `url`, `platform?` | X / Instagram / TikTok 原生 widget |
| `video` | `url`, `platform`, `thumbnail?` | YouTube / Bilibili / Vimeo 播放器 |
| `image` | `url`, `alt?` | 静态图片（Figure 组件）|

### Commit 类型

| 类型 | 必填字段 | 可选字段 |
|------|----------|----------|
| `project` | `media[]` | `techStack[]`, `stats` |
| `talk` | `conference` | `media[]` |
| `post` | `url`, `publication` | `media[]` |
| `role` | `company`, `title` | `location`, `url`, `media[]` |
| `social` | `platform` | `media[]` |
