## Widget 原语

Widget 系统基于可组合的原语构建（类似 shadcn 模式）。这些原语提供一致的样式，同时允许灵活组合。

### WidgetShell

带卡片样式的基础容器（圆角、背景模糊、边框、悬停效果）。

<WidgetShell>
  <div className="p-5">
    <span className="text-sm text-muted-foreground">
      WidgetShell 提供所有 Widget 使用的一致卡片外观。
    </span>
  </div>
</WidgetShell>

### WidgetHeader + WidgetTitle + WidgetLink

带标题和可选导航箭头的头部栏。

<WidgetShell>
  <WidgetHeader>
    <WidgetTitle>Widget 标题</WidgetTitle>
    <WidgetLink href="/docs" />
  </WidgetHeader>
  <WidgetBody>
    <span className="text-sm text-muted-foreground">
      内容放在这里。WidgetBody 提供一致的内边距。
    </span>
  </WidgetBody>
</WidgetShell>

### WidgetStatus

用于"活跃"状态的脉冲指示器（例如当前职位）。

<WidgetShell>
  <WidgetHeader className="pb-3">
    <div className="flex items-center gap-2">
      <WidgetStatus />
      <WidgetTitle>当前活跃</WidgetTitle>
    </div>
    <WidgetLink href="/works" variant="text" />
  </WidgetHeader>
  <WidgetBody>
    <span className="text-sm text-muted-foreground">
      状态指示器表示某事正在进行中。
    </span>
  </WidgetBody>
</WidgetShell>

### 自定义布局（天气样式）

WidgetShell 搭配完全自定义的内部布局。

<WidgetShell>
  <div className="p-5">
    <div className="flex items-center justify-between">
      <WidgetTitle>旧金山，加州</WidgetTitle>
      <span className="text-xs text-muted-foreground">☀️</span>
    </div>
    <div className="mt-3 flex items-end justify-between gap-4">
      <div className="font-serif text-4xl leading-none text-foreground tracking-tight tabular-nums">
        22°
      </div>
      <div className="text-xs font-mono text-muted-foreground uppercase tracking-wider">
        晴朗
      </div>
    </div>
  </div>
</WidgetShell>

## Stack Widget 属性参考

### HStackWidget / VStackWidget

| 属性 | 类型 | 默认值 | 描述 |
|------|------|--------|------|
| `title` | `string` | 必填 | 标题（以等宽大写字体显示） |
| `href` | `string` | - | 可选的"查看全部"链接 |
| `children` | `ReactNode[]` | 必填 | 要显示的子元素 |
| `className` | `string` | - | 自定义 CSS 类名 |

### 行为差异

| 特性 | HStackWidget | VStackWidget |
|------|--------------|--------------|
| 布局 | 水平滚动 | 垂直列表 |
| 滚动 | 惯性吸附滚动 | 无滚动（全部可见） |
| 分页 | 当项目 > 1 时显示点指示器 | 无 |
| 适用场景 | 带缩略图的演讲、精选项目 | 列表、文字密集内容 |

## CommitEmbed 属性参考

| 属性 | 类型 | 默认值 | 描述 |
|------|------|--------|------|
| `commit` | `Commit` | 必填 | 提交数据对象 |
| `locale` | `"en" \| "zh"` | `"en"` | 显示语言 |
| `variant` | `"timeline" \| "card" \| "bare"` | `"card"` | 显示变体（见下表） |
| `defaultExpanded` | `boolean` | `false` | 默认展开状态 |
| `className` | `string` | - | 自定义 CSS 类名 |

### 变体参考

| 变体 | 描述 | 使用场景 |
|------|------|----------|
| `timeline` | 显示图标，时间线优化间距 | /works 页面时间线 |
| `card` | 独立卡片带边框/背景 | MDX 内容（默认） |
| `bare` | 最简无框，紧凑内容 | Stack/Widget 内部 |

## 提交类型参考

每种提交类型都有特定字段：

### 通用字段（所有类型）

- `id`：唯一标识符
- `type`：类型标识（`"project"`、`"talk"`、`"post"`、`"role"`、`"social"`）
- `tagId`：父标签/时代标识符
- `date`：开始日期（`YYYY-MM` 或 `YYYY-MM-DD`）
- `endDate`：可选的结束日期
- `title`：`LocalizedString`（`{ en: string, zh: string }`）
- `description`：`LocalizedString`
- `commentary`：可选的 `LocalizedString`（个人备注）
- `tags`：可选的字符串数组，用于分类
- `listed`：可选的布尔值（默认 `true`）

### 类型特定字段

| 类型 | 必填字段 | 可选字段 |
|------|----------|----------|
| `project` | `links[]` | `techStack[]`、`stats` |
| `talk` | `conference` | `video`、`slides` |
| `post` | `url`、`publication` | - |
| `role` | `company`、`roleTitle` | `location`、`url` |
| `social` | `platform`、`url` | - |
