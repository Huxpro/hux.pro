## Widget Primitives

The widget system is built on composable primitives (shadcn-like pattern). These primitives provide consistent styling while allowing flexible composition.

### WidgetShell

The base container with card styling (rounded corners, backdrop blur, border, hover effects).

<WidgetShell>
  <div className="p-5">
    <span className="text-sm text-muted-foreground">
      WidgetShell provides the consistent card appearance used across all widgets.
    </span>
  </div>
</WidgetShell>

### WidgetHeader + WidgetTitle + WidgetLink

Header bar with title and optional navigation arrow.

<WidgetShell>
  <WidgetHeader>
    <WidgetTitle>Widget Title</WidgetTitle>
    <WidgetLink href="/docs" />
  </WidgetHeader>
  <WidgetBody>
    <span className="text-sm text-muted-foreground">
      Content goes here. WidgetBody provides consistent padding.
    </span>
  </WidgetBody>
</WidgetShell>

### WidgetStatus

Pulsing status indicator for "active" states (e.g., current role).

<WidgetShell>
  <WidgetHeader className="pb-3">
    <div className="flex items-center gap-2">
      <WidgetStatus />
      <WidgetTitle>Currently Active</WidgetTitle>
    </div>
    <WidgetLink href="/log" variant="text" />
  </WidgetHeader>
  <WidgetBody>
    <span className="text-sm text-muted-foreground">
      Status indicator shows something is currently in progress.
    </span>
  </WidgetBody>
</WidgetShell>

### Custom Layout (Weather-style)

WidgetShell with fully custom internal layout.

<WidgetShell>
  <div className="p-5">
    <div className="flex items-center justify-between">
      <WidgetTitle>San Francisco, CA</WidgetTitle>
      <span className="text-xs text-muted-foreground">☀️</span>
    </div>
    <div className="mt-3 flex items-end justify-between gap-4">
      <div className="font-serif text-4xl leading-none text-foreground tracking-tight tabular-nums">
        22°
      </div>
      <div className="text-xs font-mono text-muted-foreground uppercase tracking-wider">
        Clear
      </div>
    </div>
  </div>
</WidgetShell>

## Stack Widget Props Reference

### HStackWidget / VStackWidget

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `title` | `string` | required | Header title (displayed in mono uppercase) |
| `href` | `string` | - | Optional link for "view all" arrow |
| `children` | `ReactNode[]` | required | Child elements to display |
| `className` | `string` | - | Additional CSS classes |

### Behavior Differences

| Feature | HStackWidget | VStackWidget |
|---------|--------------|--------------|
| Layout | Horizontal scroll | Vertical list |
| Scroll | Snap scrolling with momentum | No scroll (all visible) |
| Pagination | Dot indicators when > 1 item | None |
| Best for | Talks with thumbnails, featured items | Lists, text-heavy content |

---

## CommitEmbed Props Reference

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `commit` | `Commit` | required | The commit data object |
| `locale` | `"en" \| "zh"` | `"en"` | Display locale for i18n |
| `variant` | `"timeline" \| "card" \| "bare"` | `"card"` | Display variant (see below) |
| `defaultExpanded` | `boolean` | `false` | Start in expanded state |
| `className` | `string` | - | Additional CSS classes |

### Variant Reference

| Variant | Description | Use Case |
|---------|-------------|----------|
| `timeline` | Shows icon, timeline-optimized spacing | /log page timeline |
| `card` | Standalone with border/bg frame | MDX content (default) |
| `bare` | Minimal frameless, compact content | Inside stacks/widgets |

## Commit Type Reference

Each commit type has specific fields:

### Common Fields (All Types)

- `id`: Unique identifier
- `type`: Discriminator (`"project"`, `"talk"`, `"post"`, `"role"`, `"social"`)
- `tagId`: Parent tag/era identifier
- `date`: Start date (`YYYY-MM` or `YYYY-MM-DD`)
- `endDate`: Optional end date
- `title`: `LocalizedString` (`{ en: string, zh: string }`)
- `description`: `LocalizedString`
- `commentary`: Optional `LocalizedString` (personal notes)
- `tags`: Optional string array for categorization
- `listed`: Optional boolean (default `true`)

### Type-Specific Fields

| Type | Required Fields | Optional Fields |
|------|-----------------|-----------------|
| `project` | `links[]` | `techStack[]`, `stats` |
| `talk` | `conference` | `video`, `slides` |
| `post` | `url`, `publication` | - |
| `role` | `company`, `roleTitle` | `location`, `url` |
| `social` | `platform`, `url` | - |
