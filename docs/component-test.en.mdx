# Component Test

This document demonstrates all widget-like components and their variants, organized from smallest composable units to larger compositions.

## Terminology

- **Media**: Atomic external content units (video, embed, link, image)
- **Commit**: A work item (project, talk, post, role, social) that can have Media attached
- **Embed**: Specifically the native social platform widgets (Twitter, Instagram, TikTok)

---

## 1. Media

Media components are the atomic building blocks for embedding external content. The `Media` component auto-detects platform and renders the appropriate embed.

### Component Hierarchy

```
                    Media (unified entry)
                           │
             ┌─────────────┼─────────────┐
             │             │             │
           Video         Embed      LinkPreview
             │             │
      ┌──────┼──────┐  ┌───┴───┐
      │      │      │  │   │   │
  YouTube  Bili  Vimeo  X  IG TikTok
```

- **Media**: Unified entry point, auto-detects URL and routes to the appropriate component
- **Video**: Video platforms with click-to-play thumbnails
- **Embed**: Native social platform widgets using official SDKs
- **LinkPreview**: OG card preview for other URLs

### Media (Forced Type)

Use the `as` prop to force a specific rendering mode, bypassing auto-detection. This is useful when you want to render a URL differently than its detected type.

<Playground>

## Quick Reference

### Media Types

| Type | Properties | Description |
|------|------------|-------------|
| `video` | `url`, `platform` | YouTube, Bilibili |
| `embed` | `url` | Twitter, Instagram, TikTok |
| `link` | `url`, `label?`, `icon?`, `showPreview?` | External links |
| `image` | `url`, `alt?` | Static images (Figure component) |

### Commit Types

| Type | Required Fields | Optional Fields |
|------|-----------------|-----------------|
| `project` | `media[]` | `techStack[]`, `stats` |
| `talk` | `conference` | `media[]` |
| `post` | `url`, `publication` | `media[]` |
| `role` | `company`, `title` | `location`, `url`, `media[]` |
| `social` | `platform` | `media[]` |
