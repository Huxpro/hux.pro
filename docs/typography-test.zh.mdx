## WorkItemEmbed 组件

`WorkItemEmbed` 组件允许在 MDX 内容中直接嵌入工作项目。支持 5 种类型：**project（项目）**、**talk（演讲）**、**post（文章）**、**role（职位）** 和 **social（社交）**。

每个类型使用：
- `LocalizedString` 对象用于国际化：`{ en: "...", zh: "..." }`
- 嵌套对象用于相关字段（如 `conference`、`video`、`publication`）
- 联合类型用于类型安全

### 示例：项目

<WorkItemEmbed
  item={{
    id: "example-project",
    type: "project",
    eraId: "demo",
    title: { en: "Design System Tokens", zh: "设计系统令牌" },
    description: {
      en: "A comprehensive design token system for building consistent, themeable UI components.",
      zh: "一个全面的设计令牌系统，用于构建一致的、可主题化的 UI 组件。支持 CSS 变量、Tailwind 和多种输出格式。"
    },
    date: "2024-01",
    links: [
      { url: "https://example.com/tokens", label: "网站", icon: "globe" },
      { url: "https://github.com/example/tokens", label: "GitHub", icon: "github" }
    ],
    techStack: ["TypeScript", "CSS", "Tailwind"],
    commentary: {
      en: "This project taught me a lot about systematic design thinking.",
      zh: "这个项目教会了我很多关于系统化设计思维的知识。"
    },
    stats: { stars: 1200, downloads: "50k/mo" }
  }}
  locale="zh"
/>
