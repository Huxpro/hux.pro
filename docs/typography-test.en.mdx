## CommitEmbed Component

The `CommitEmbed` component allows embedding commits (work items) directly in MDX content. It supports 5 types: **project**, **talk**, **post**, **role**, and **social**.

Each type uses:
- `LocalizedString` objects for i18n: `{ en: "...", zh: "..." }`
- Nested objects for related fields (e.g., `conference`, `video`, `publication`)
- Discriminated union types for type safety

### Example: Project

<CommitEmbed
  commit={{
    id: "example-project",
    type: "project",
    tagId: "demo",
    title: { en: "Design System Tokens", zh: "设计系统令牌" },
    description: {
      en: "A comprehensive design token system for building consistent, themeable UI components. Supports CSS variables, Tailwind, and multiple output formats.",
      zh: "一个全面的设计令牌系统，用于构建一致的、可主题化的 UI 组件。"
    },
    date: "2024-01",
    links: [
      { url: "https://example.com/tokens", label: "Website", icon: "globe" },
      { url: "https://github.com/example/tokens", label: "GitHub", icon: "github" }
    ],
    techStack: ["TypeScript", "CSS", "Tailwind"],
    commentary: {
      en: "This project taught me a lot about the importance of systematic design thinking.",
      zh: "这个项目教会了我很多关于系统化设计思维的知识。"
    },
    stats: { stars: 1200, downloads: "50k/mo" }
  }}
  locale="en"
/>
